- 合計の計算：49頭すべて再計算したところ、表の合計と5能力の和は全頭一致。計算の誤りは見つからなかった。

## 3. 各馬の個性

- **ハヤチネグリフォン**（岩手・早池峰の幻獣・黒鹿毛）霊峰・早池峰の名を背負うパワー型。坂のあるコースと消耗戦で真価を発揮する。 弱点：速さ78。高速決着では置いていかれる。
- **ダテマサムネ**（宮城・独眼の策士・青鹿毛）伊達男らしい派手な末脚と冷静な判断力。直線で外へ持ち出す手綱さばきが光る。 弱点：持久79。長距離では最後に脚が上がる。
- **オガノライデン**（秋田・男鹿の雷神・栗毛）なまはげの里から来た雷のような馬力。重い馬場を一気に押し切る。 弱点：切れ味勝負に弱い。
- **デワノキセキ**（山形・出羽三山の奇跡・鹿毛）修験の山で鍛えた粘り強さ。最後の最後で奇跡のように伸びてくる。 弱点：力78。急坂のコースで苦しむ。
- **アイヅクロニクル**（福島・会津の年代記・黒鹿毛）不屈の会津魂。持久力と根性で長丁場の我慢比べを制する。 弱点：速さ78。短い距離では追走に苦労する。

- **リュウキュウティーダ**（沖縄・琉球の太陽・栗毛）速さ94。南国の太陽のような高速決着が得意。 弱点：力76。重馬場は大の苦手。
- **アメリカンエクスプレス**（アメリカ・海を渡った刺客・鹿毛）決勝にだけ姿を現すアメリカからの招待馬。すべてが高水準の均整型。 弱点：日本の重い馬場は未経験。

## 4. レースの仕組み

- 4頭立て。予選12組（短距離・マイル・中距離・長距離を3組ずつ）→準決勝3組→決勝（東京芝2400m、3頭＋アメリカンエクスプレス）。
- 組み合わせ：能力順に4つのつぼに分けて各組に1頭ずつ、同じ地域ができるだけ重ならないよう抽選。
- 競馬場10場の直線の長さ・坂・洋芝、馬場4段階、調子4段階、見えない当日の出来で勝敗が揺れる。
- 能力の役割：速＝最高速、持＝スタミナ量、力＝加速・坂・重馬場、根＝競り合いとバテてからの粘り、賢＝出遅れ・掛かり・前が壁の回避・スタミナの節約。
- 気合い（プレイヤーのみ、1レース10回）：3秒間だけ伸びる代わりにスタミナを多く使う。残り600mから10回使い切ると勝率が約24%→42%（シミュレーション値）。
- 検証値（ランダム4頭×数千レース）：各馬の1着率はおよそ16〜36%、脚質別は22〜29%、合計点と勝率の相関は約0.1〜0.3。
