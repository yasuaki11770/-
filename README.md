## その瞬間、あなたは（救急対応ストーリーゲーム・試作版）

`kyukyu/` フォルダ。一般市民の立場（17歳の高校生・春日康太）で、家族や友人の急病・事故・災害に向き合う救急対応ストーリーゲーム。脳卒中、心臓震盪、窒息、溺水、交通事故、熱傷、アナフィラキシー、熊本地震のエコノミークラス症候群、クラッシュ症候群、一酸化炭素中毒、低血糖、鼻出血、ムカデ咬傷、頭部外傷、ボタン電池誤飲など全17症例。判断で時間が進み、結末が変わる。症例後に一般向けの解説と、医学生・医療者向けの補足つき。

教育目的のフィクションです。実際の緊急時は119番（海の事故は118番）へ。

## この美しいまちに住む、あなたへ ―南海トラフ地震

`tsunami/` フォルダ。四万十市・幡多の8人の物語で、南海トラフ地震と津波から生き延びる判断を学ぶ、選択肢で進む物語ゲーム。「その瞬間、あなたは」と同じ仕組み。入野・下田・中村の3つの舞台で、少女・サーファー・技能実習生（二部構成）・先生・消防団員・主婦・外来患者・入院患者の物語と、8本すべてを終えると開くエピローグ「その夜」を遊べる。設計は `tsunami/DESIGN.md`、幡多弁の確認リストは `tsunami/HATABEN.md`。

- 編集は `tsunami/src/` の部品で行い、`python3 tsunami/build.py` で `tsunami/index.html` を作る
- ふりがな：手の辞書 `src/45_ruby.js` と、形態素解析（kuromoji）で作る `src/46_ruby_auto.js`（`tools/make_ruby.js`）
- テスト：`node tsunami/tools/playall.js best|worst|random`（全物語の自動通しプレイ）
- 人物と出来事は架空。場所は実在するが、学校・病院・お店・消防団の実際の避難計画とは関係ない
