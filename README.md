# マジックシティ地下迷宮

マジックシティの坑道20階に挑む、3Dダンジョン×一騎打ちRPG。ヤスとシュウ、2人の主人公。

ブラウザで遊べます（スマホ対応）。プレイには three.js を読み込むためネット接続が必要です。セーブはブラウザに保存されます。

## 三國志決戦伝（`kessen/`）

「三国決戦伝」の合戦（3Dの戦場、軍議・陣形・軍略、武将の性格と戦法、一騎打ち英雄伝の一騎打ち、音楽）をそのまま使い、
英傑伝のように会話シーンで物語を進める形に作り替えた別アプリ。
桃園の誓いから晋の天下統一まで、全7章・113シーン（うち合戦34）。三国志の名場面116個をすべて収録し、「名場面録」から見返せる。

- `kessen/index.html` を開くだけで遊べる（通信なし）
- 作り方：`python3 kessen/build.py`。三国決戦伝そのもの（`kessen/src/base.html`）に、物語の台本（`src/story1〜4.js`）・合戦表（`src/wars.js`）・物語の仕組み（`src/story_mode.js`）を足して `index.html` を書き出す
