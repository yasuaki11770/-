# マジックシティ地下迷宮

マジックシティの坑道20階に挑む、3Dダンジョン×一騎打ちRPG。ヤスとシュウ、2人の主人公。

ブラウザで遊べます（スマホ対応）。プレイには three.js を読み込むためネット接続が必要です。セーブはブラウザに保存されます。

## その瞬間、あなたは（救急対応ストーリーゲーム・試作版）

`kyukyu/` フォルダ。一般市民の立場（17歳の高校生・春日康太）で、家族や友人の急病・事故・災害に向き合う救急対応ストーリーゲーム。脳卒中、心臓震盪、窒息、溺水、交通事故、熱傷、アナフィラキシー、熊本地震のエコノミークラス症候群、クラッシュ症候群、一酸化炭素中毒、低血糖、鼻出血、ムカデ咬傷、頭部外傷、ボタン電池誤飲など全17症例。判断で時間が進み、結末が変わる。症例後に一般向けの解説と、医学生・医療者向けの補足つき。

教育目的のフィクションです。実際の緊急時は119番（海の事故は118番）へ。

## 名作のなかへ（読書百選ゲーム・試作版）

`dokusho/` フォルダ。本が読めなくても、名作の中に入って主人公として名場面を体験できる。

1. **本の世界**：主人公になって名場面を進む。初期設定では選択肢なしで原作の流れのまま読み進め、「記録と設定」で選択肢ありにすると、原作の主人公と違う選択をしたときにページが波打ち、ふくろうの司書・ミネル先生が「原作ではこうした」と教えてくれる
2. **名作のわけ**：なぜ読み継がれてきたのかを、作者の生涯や成り立ち、文章の工夫から先生が語る
3. **問いかけ**：「この名作から学べることで、改めたいことはないか？」――栞にはさめる言葉はひとつだけ。選ぶか、自分の言葉で書く（以前の「いまのあなたは、こんな自分になっていないか？」は、栞の問いかけと重なるのでやめた）

- 収録：読書百選の158冊すべて（中等部100冊・高等部100冊）。伝記・随筆・歌集・詩集は、作者の人生の場面に入る形
- 著作権の保護期間中の作品は本文を引用せず独自の言葉で書き、海外の作品は既存の邦訳を使わずに原作から書いた
- 人の死や差別を扱う作品は描写を控えめにし、必要に応じて相談窓口（24時間子供SOSダイヤル）を案内
- 本のページには読了日・自分の栞が残り（以前の問いかけに答えた本は、そのときの答えも）、あとから問いかけだけ答え直せる
- 本棚には、中等部・高等部「読書100選」を重複なしで統合した158冊が並ぶ（一覧は `dokusho/books.md`）
- 本棚は、背表紙（1段10冊）・表紙・リスト・わたしの本の4通りで見られ、あいうえお順（「あ行」「か行」…に分けて表示）ほか、評価や年代でも並べかえられる。書名・作者での検索もできる
- 本の印：アプリで読みおえた本は金の外枠で囲む。しおりは、持っている本が外枠だけ、紙の本で読んだ本が塗りつぶし
- 本の質感：1950年以降の本は紙の本、1900年代前半の本は布張り（織り目と金の線）、それより古い本は革装（背のバンドと金箔押しの題）。背表紙は丸みの陰影・手ざわり・図書館ラベル、表紙は綴じの溝と、横からのぞく紙の束で本物らしく見せる。本棚は木の棚板に1段10冊、厚い本は太く、短い本は細く並ぶ
- 読みやすさ：背表紙の題名と物語の本文には、読みやすさを重視したUDフォント（BIZ UDP明朝）を使う。背表紙の長い題名は「の」「・」などの切れ目で2列に分けて大きく見せ、本文の文字の大きさは「記録と設定」で小・中・大・特大から選べる
- 本棚では、書かれた時代の古い本ほど、色あせ・しみ・すり切れのある使いこまれた姿で並ぶ
- 本ごとに「本で読んだ日」「好き度（♥5段階）」「自由な感想」を記録できる
- 栞帳：これまでにはさんだ栞を、読んだ日・好き度・感想といっしょに一覧で見返せる
- 読了のハンコ：表紙に「読了」のハンコを押す。アプリで読了だけ＝青、アプリと本の両方＝赤、本で読んだだけ＝緑（日付入り）。本棚の背表紙は、同じ色の縁どりで光る
- 本のページ：表紙と題（所要時間もここに）の下に、操作（扉を開く・問いかけにもう一度）、その下に「この本のめやす」を開いたまま。名作のわけ・あらすじ・本物を読むなら・表紙・わたしの記録は、見出しをタップして開く折りたたみ。「本棚へ戻る」は一番下。「持っている」は、わたしの記録の中（と、背表紙のカード・リスト）で切りかえる。表紙の選択は、持っている本だけに出る。読了したばかりのときは「本棚へ戻る」だけ
- 漢字づかい：大人の読者向けに、物語・ミネル先生の言葉・問いかけの文の、漢字のほうが読みやすい語を漢字にしている（「つめたい→冷たい」「ふるえる→震える」など約9,700か所）。原作の引用・書名・詩・登場人物のあだ名・わざとひらがなで書いた文は、そのまま。道具は `dokusho/tools/kanji/`
- 図書館のオルゴール：本棚の上の「♪」ボタン（または「記録と設定」）でオンにすると、オリジナルのオルゴール曲が流れる。曲は「遠い日の図書館」（映画音楽のような、なつかしくて切ない曲。ヘ長調からト長調へ転調）、「栞のワルツ」（変ホ長調・3拍子）、「交互に」から選べ、本棚の「⇄ 曲」でもすぐ入れかえられる。本の中でも流れつづけ、ほかのアプリに切りかえると止まる。初期値はオフ。曲は `dokusho/tools/orgel2.py`・`orgel.py`（numpy と ffmpeg）で楽譜から合成している
- 大人の読者向けのことば：ミネル先生の話す言葉と、読後の問いかけの項目は、大人の読者を想定して表示する（adult.js）。呼びかけは「あなた」、学校生活を前提にした例えは職場や暮らしの例えに、相談先は大人向けの窓口（よりそいホットライン、子どもの虐待に気づいたときの「189」）に置きかえ、ひらがなで開いていた語の一部を漢字に、句ごとの読点を大人の文章の呼吸に整える。物語の地の文・登場人物の台詞・「」『』の引用・太字の原作の言葉は変えない
- ミネル先生のおすすめ：短くて読みやすい本から少しずつ長い本へ進む「次の一冊」と、日がわりの「今日の一冊」
- 節目のごほうび：10・50・100・150冊（その先は50冊ごと）と全刊で、ミネル先生のことばがあり、栞の色が若葉・藍・金・星空・金地にふくろうの紋と変わる
- 「わたしの本」：持っている本だけを、写真の表紙で並べて見られる
- 学校の読書記録用の一覧：中等部（日本50冊・海外50冊）・高等部（100冊）の番号順に、本で読んだ日を表にして印刷できる（PDF保存も可）
- 感想文の下書き：栞の言葉・読んだときの自分・好き度・感想を、ひとつの文章にまとめてコピーできる（書きたすところは（　）で案内）
- 記録のバックアップ：読了・栞・感想・本で読んだ日・持っている本・表紙の写真を1つのファイルに書き出し、別の端末で読みこめる
- 表紙には本ごとに絵がある。持っている本は、自分の本の写真を撮って表紙にでき、絵と写真を切りかえられる（写真はその端末の中だけに保存）

## 午後の書斎（人生の午後の15作・試作版）

`gogo/` フォルダ。公開URL：https://yasuaki11770.github.io/-/gogo/

「名作のなかへ」と同じ仕組みで作った、大人向けの別サイト。本だけでなく、映画・漫画・記録映画・詩集も、同じスタイルで「主人公になって入る」。案内役は、夜更けの書斎のマスター。

1. **作品の世界**：主人公になって名場面を進む（初期設定は選択肢なし。「記録と設定」で選択肢ありにすると、原作と違う道でページが波打つ）。物語のない本（自己啓発・古典）は、「その本が語りかけている人」になって場面を体験する
2. **名作のわけ**：なぜ長く心に残ってきたのかを、マスターが四つの話で語る
3. **問いかけ**：「この作品から、これからの人生に持って帰りたいものは？」――栞の言葉を一つ選ぶか、自分の言葉で書く

- 収録：遠い太鼓／人生後半の戦略書／PERFECT DAYS／グリーンブック／宇宙兄弟／DIE WITH ZERO／生の短さについて／異文化理解力／人生フルーツ／月と六ペンス／いま、希望を語ろう／ノマドランド／嫌われる勇気／ストーナー／倚りかからず
- 著作権の保護期間中の作品は、本文・台詞・詩を引用せず、独自の言葉で書いている。古典（セネカ・モーム）の引用は、このサイトでの独自の訳
- 実在の人物（カラニシ医師、津端夫妻、茨木のり子など）は、本や映画で公に語られている範囲で、敬意をもって描いている
- 本棚・表紙・栞帳・好き度・感想・バックアップ・オルゴールなど、読了のハンコ（アプリだけ＝青、アプリと実物＝赤、実物だけ＝緑）、本のページの折りたたみなど、「名作のなかへ」の機能をそのまま使える（記録は「名作のなかへ」とは別に保存される）。映画はディスクのケースの姿で棚に並ぶ
- 名作のなかへ との違い：しおりができた画面には「好き？」と感想の欄を出さない（本のページの「わたしの記録」で書く）。感想を一つの文章にまとめる（感想文の下書き）ボタンもない
- 仕組みは `gogo/build_from_dokusho.py` で `dokusho/` から作る（engine.js・index.html・art.js）。作品のデータは `gogo/books.js` と `gogo/ep_*.js`
