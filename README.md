# マジックシティ地下迷宮

マジックシティの坑道20階に挑む、3Dダンジョン×一騎打ちRPG。ヤスとシュウ、2人の主人公。

ブラウザで遊べます（スマホ対応）。プレイには three.js を読み込むためネット接続が必要です。セーブはブラウザに保存されます。

## 白球ナイン（`baseball/`）

四国の高校野球部の監督になって、3年以内の甲子園優勝をめざす観戦型の高校野球ゲーム。

- 練習は週ごとに方針（バランス・打撃・守備走塁・投手・休養）を選ぶだけ。
- 試合は3Dの球場で観戦しながら、強振・ミート・待て・バント・盗塁・勝負・慎重・敬遠・投手交代の簡単な指示を出す。「結果だけ見る」「結果まで飛ばす」もできる。
- 1年の流れ：新入生入部 → 練習試合 → 夏の県大会 → 夏の甲子園 → 3年生引退 → 秋の県大会 → 四国大会 → センバツ選考 → 春のセンバツ。延長10回からはタイブレーク。
- 球場は1つを使い回し、県ごとに色味とフェンスの高さを変えた（高知 2.4m < 愛媛 3.0m < 香川 3.6m < 徳島 4.4m、甲子園 3.4m）。フェンスが低いほど本塁打が出やすい。
- 選手は「四国カルチョ」の4県の選手たちが高校球児として登場。球場と試合エンジンは「三国スタジアム」をもとに、三国志の要素を外して作り直した。
