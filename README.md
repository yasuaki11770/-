## その瞬間、あなたは（救急対応ストーリーゲーム・試作版）

`kyukyu/` フォルダ。一般市民の立場（17歳の高校生・春日康太）で、家族や友人の急病・事故・災害に向き合う救急対応ストーリーゲーム。脳卒中、心臓震盪、窒息、溺水、交通事故、熱傷、アナフィラキシー、熊本地震のエコノミークラス症候群、クラッシュ症候群、一酸化炭素中毒、低血糖、鼻出血、ムカデ咬傷、頭部外傷、ボタン電池誤飲など全17症例。判断で時間が進み、結末が変わる。症例後に一般向けの解説と、医学生・医療者向けの補足つき。

教育目的のフィクションです。実際の緊急時は119番（海の事故は118番）へ。

## 名作のなかへ（読書百選ゲーム・試作版）

`dokusho/` フォルダ。本が読めなくても、名作の中に入って主人公として名場面を体験できる。

1. **本の世界**：主人公になって名場面を進む。原作の主人公と違う選択をするとページが波打ち、ふくろうの司書・ミネル先生が「原作ではこうした」と教えてくれる
2. **名作のわけ**：なぜ読み継がれてきたのかを、作者の生涯や成り立ち、文章の工夫から先生が語る
3. **問いかけ その一**：「いまのあなたは、こんな自分になっていないか？」――登場人物に重なる今の自分を選ぶと、先生が答えてくれる
4. **問いかけ その二**：「この名作から学べることで、改めたいことはないか？」――栞にはさめる言葉はひとつだけ。選ぶか、自分の言葉で書くと、それが自分の栞になる

- 収録：中等部「読書100選」の100冊すべて＋高等部のみの本24冊（計124冊／158冊）。伝記・随筆・歌集・詩集は、作者の人生の場面に入る形
- 著作権の保護期間中の作品は本文を引用せず独自の言葉で書き、海外の作品は既存の邦訳を使わずに原作から書いた
- 人の死や差別を扱う作品は描写を控えめにし、必要に応じて相談窓口（24時間子供SOSダイヤル）を案内
- 本のページには読了日・自分の栞・読んだときの自分が残り、あとから問いかけだけ答え直せる
- 本棚には、中等部・高等部「読書100選」を重複なしで統合した158冊が並ぶ（一覧は `dokusho/books.md`）
