# マジックシティ地下迷宮

マジックシティの坑道20階に挑む、3Dダンジョン×一騎打ちRPG。ヤスとシュウ、2人の主人公。

ブラウザで遊べます（スマホ対応）。プレイには three.js を読み込むためネット接続が必要です。セーブはブラウザに保存されます。

## 三國志決戦伝（`kessen/`）

「三国決戦伝」を、会話シーンとマス目の合戦で物語をたどるシミュレーションRPGに作り替えた別アプリ。
桃園の誓いから晋の天下統一まで、全7章・113シーン（うち合戦34）。三国志の名場面116個をすべて収録し、「名場面録」から見返せる。

- 合戦：自軍の部隊を動かして攻撃・計略（火計・落石・混乱・援助など）。騎兵＞歩兵＞弓兵＞騎兵の三すくみ、地形効果あり
- 一騎打ち：因縁の武将同士がぶつかると名場面の一騎打ち（温酒斬華雄、三英戦呂布、五関突破など）
- 武将の顔と台詞は三国決戦伝から引き継いでいる
- 難易度（やさしい／ふつう）、速さ、音は「設定」で変えられる
- `kessen/index.html` を開くだけで遊べる（ネット接続なしでも動く。フォントだけネットから読む）
