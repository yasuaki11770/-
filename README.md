# マジックシティ地下迷宮

マジックシティの坑道20階に挑む、3Dダンジョン×一騎打ちRPG。ヤスとシュウ、2人の主人公。

ブラウザで遊べます（スマホ対応）。プレイには three.js を読み込むためネット接続が必要です。セーブはブラウザに保存されます。


# 逆転の采配

不利な側が指揮官の判断で勝った戦を、自分で指揮して勝つゲーム。`saihai/index.html` をブラウザで開いて遊べます（スマホ対応）。

どの戦も、最後は兵がリアルタイムで動く決戦（部隊をタップして選び、行き先か敵をタップ）。

| 戦 | 遊び方 |
|---|---|
| 桶狭間の戦い（1560） | 奇襲。豪雨にまぎれて義元の本陣を突く |
| スターリング・ブリッジ（1297） | 狭い橋を敵がちょうどよい数だけ渡った瞬間を狙う |
| 背水の陣（前204） | 三つの隊に同時に命令。囮で敵を誘い、空の砦を奪う |
| 木崎原の戦い（1572） | 釣り野伏せ。伏兵を両側にかくし、三方から包む |
| オルレアンの乙女（1429） | 士気で戦う。砦を落とす順番とジャンヌの決断 |
| 鳴梁海戦（1597） | 潮が変わるまで海峡の出口で持ちこたえる |
| ロルクズ・ドリフト（1879） | 壁を築き、守る場所を選び、一晩を守り抜く |
| カンナエの戦い（前216） | 陣形を選び、中央を下げて敵を包みこむ |
